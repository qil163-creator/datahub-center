# Asset 模块约束

本文件适用于 `yudao-module-asset/**`，与仓库根 `AGENTS.md` 同时生效。

- Asset 拥有资产目录、检索、标签、收藏、血缘消费、数据市场和授权申请等领域状态；上游元数据、治理、数据源或供应能力通过提供方 `*-api` 或正式事件合同接入，不直接依赖对方 `*-server` 或业务表。
- 搜索索引、缓存、推荐结果和通知是派生视图，不能代替数据库中的权威资产、授权或申请状态。更新链路要定义事务提交后的失效/刷新、重复事件、乱序、重建和对账。
- 列表、详情、导出、收藏、申请、审批和交付必须分别明确平台、部门或对象级数据范围；前端可见、菜单权限或客户端传入的 owner/tenant 不能代替服务端 Guard。
- 市场发布、下架、授权、审批和强制变更使用显式状态机、幂等键和领域审计。跨服务结果可能失败或未知时保存可恢复状态，并提供重试、补偿或对账路径。
- 文件仍通过 infra `FileApi` 或经验证的预签名/流式协议处理；大文件不得塞入无上限 `byte[]`。对象上传与平台元数据登记是两阶段结果，需要处理登记失败和孤儿对象。
- 新增平台表、字典、菜单、权限或修复数据时提交全局编号 PostgreSQL 迁移，并同步核对后端权限注解、前端权限字符串和菜单组件路径。
