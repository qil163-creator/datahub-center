# 数据库类型图标缩略图设计

## 目标

数据库类型列表中的 `iconPath` 字段不再显示 URL 文本，而是显示对应图片的缩略图。用户点击缩略图时可以预览原图。

## 方案比较

1. 使用项目已注册的 `CellImage` 表格渲染器（采用）
   - 与数据库驱动、系统来源等现有列表保持一致。
   - 改动范围最小，不新增组件或重复样式。
   - 沿用图片组件的加载失败、空值与预览行为。
2. 在页面中增加 `iconPath` 插槽并手写图片组件
   - 可以单独控制尺寸和占位内容。
   - 需要增加模板代码，且会重复项目已有能力。
3. 在列配置中直接使用 `h('img')`
   - 实现简单。
   - 缺少现成的点击预览能力，错误与空值处理也需要自行补充。

## 设计

- 修改 `apps/web-antdv-next/src/views/foundation/databasetype/data.ts` 中的 `iconPath` 列。
- 列标题由“数据源图标路径”调整为“数据源图标”，使标题与实际展示内容一致。
- 为该列配置 `cellRender: { name: 'CellImage' }`。
- 不改变接口字段、上传表单、后端数据或其他列表列。

## 验收

- 有效图片 URL 在列表中显示为缩略图，不再显示路径文本。
- 点击缩略图可以预览原图。
- 其他字段、分页、勾选和操作按钮行为不受影响。
- 前端类型检查通过。
